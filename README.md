# C盘空间深度检测与优化大师 (DiskCleanPro)

一款专为 Windows 用户与开发者打造的 **C盘空间暴降深度排查、智能清理与虚拟内存无损迁移工具**。

告别传统清理软件“盲目扫描、不敢删除、治标不治本”的痛点，精准定位吞噬 C 盘数十 GB 空间的系统底层元凶（如动态膨胀的 `pagefile.sys`、失控的 VSS 卷影快照、WinSxS 更新残留等），并提供一键安全优化。

---

## 📸 核心特性与界面一览

- **顶部系统健康仪表盘**：实时监控 C 盘、辅助数据盘（如同一 SSD 分区 H 盘）容量百分比、物理 RAM 负载及虚拟内存提交压力。
- **高占用与隐藏文件深度解析表**：
  - 覆盖系统保护、虚拟内存、组件存储、开发运行时（Puppeteer、Codex、OpenCode）、开发工具缓存（微信开发者工具）、浏览器及社交聊天数据。
  - **支持表格列宽自由拖拽拉伸与收缩**，长文本说明完整阅读不截断。
  - **支持按实际占用体积数值升降序排列**，超过 1GB/5GB 智能高亮告警。
  - **安全级别 Badge 标记**：清楚标注每一项是“安全可清”、“系统托管/迁移”还是“建议客户端内管理”，绝不误删用户个人工作文件。
- **全套一键深度优化动作**：
  - ⚡ **一键安全清理**：安全清除临时中转文件、Puppeteer/Codex 废弃无头浏览器二进制及 Chrome 缓存。
  - 🛡️ **卷影配额锁定优化**：将 C 盘卷影副本存储上限限制为 4GB，自动裁切历史过期快照，彻底阻断 Windows 自动打快照吃满 15GB。
  - 🚀 **虚拟内存一键迁移**：一键将膨胀的 `pagefile.sys` 迁移至空间充裕的同一 SSD 分区（如 H 盘），享受完全相同的 4K 读写性能，瞬间为系统盘腾出 10~20GB。
  - 🧹 **DISM 组件深度清理**：调用底层系统引擎清理被新补丁取代的历史更新包并重置基准线。
- **实时控制台执行日志**：透明化展示每一条系统指令与释放的具体 MB/GB 字节数。

## 🚀 快速上手使用

### 方式一：直接运行独立执行程序（推荐）

1. 进入 `release/` 目录；
2. 双击运行 **`DiskCleanPro.exe`**；
3. 程序内置了 Windows UAC 管理员提权清单，在弹出的 UAC 提示窗口点击“是”即可直接获得对系统卷影副本与注册表的管理权限；
4. 启动后程序将自动执行首次全盘快速扫描，按需点击操作栏按钮即可完成系统盘空间优化。

---

### 方式二：从源码运行与二次开发

#### 1. 环境准备
- 操作系统：Windows 10 / Windows 11 (64位)
- Python 版本：Python 3.10+ (已在 Python 3.14 下完整验证)

#### 2. 安装依赖
在项目根目录下打开终端执行：
```bash
pip install -r requirements.txt
```

#### 3. 运行源码
```bash
python src/main.py
```

#### 4. 一键重新编译打包为 EXE
如果修改了源码并希望重新打包输出免安装单文件应用程序：
```bash
python build.py
```
构建脚本将自动处理资源引用与 Windows 清单，并将最终产物输出至 `release/DiskCleanPro.exe`。

| :--- | :--- | :--- | :--- | :--- |
| **C 盘分页文件 (`pagefile.sys`)** | `C:\pagefile.sys` | Windows 虚拟内存交换文件。当系统连续开机或开发多任务高负载时，Windows 会自动将其动态膨胀（曾膨胀至 19GB 占满系统盘）。 | 🟡 系统托管 | 迁移至同一物理 SSD 的其他分区（如 H 盘），重启后自动释放 C 盘空间。 |
| **系统卷影快照 (VSS 还原点)** | `C:\System Volume Information` | 记录 Windows 关键系统状态、更新还原点以及文件系统的差异历史扇区。自动生成快照时极易吃掉 10~15GB。 | 🟡 系统托管 | 使用工具将配额上限锁定为 4GB，系统将自动裁剪超出配额的陈旧快照。 |
| **Windows 组件存储 (WinSxS)** | `C:\Windows\WinSxS` | 存放不同版本的系统补丁、动态链接库与回滚包。安装安全更新后存在大量已被替代的冗余历史包。 | 🟡 系统托管 | 通过工具调用 DISM 工具执行组件存储清理与基准线收缩。 |
| **用户临时文件 (User Temp)** | `%LOCALAPPDATA%\Temp` | 各类软件安装包解压释放、日常运行产生的无用临时中转文件。 | 🟢 安全可清 | 点击“一键安全清理”随时清空。 |
| **系统临时文件 (Windows Temp)** | `C:\Windows\Temp` | 操作系统内核服务、更新打入过程中生成的临时缓存。 | 🟢 安全可清 | 点击“一键安全清理”随时清空。 |
| **Puppeteer 无头浏览器** | `~/.cache/puppeteer` | 自动化脚本及爬虫拉取的 Chromium/Chrome 完整二进制安装包。 | 🟢 安全可清 | 可安全清空，未来需要时开发环境会自动拉取。 |
| **Codex / AI 辅助运行环境** | `~/.cache/codex-runtimes` | 本地代码沙箱及 AI 助手环境依赖运行时缓存。 | 🟢 安全可清 | 可安全清空，随时释放 1GB+ 空间。 |
| **OpenCode 镜像缓存** | `~/.cache/opencode` | 开源辅助工具的本地镜像与依赖包。 | 🟢 安全可清 | 可安全清空。 |

## ❓ 常见问题答疑 (FAQ)

### Q1: 虚拟内存迁移到 H 盘会不会影响系统速度？
**答：完全不会。**  
若 C 盘与 H 盘物理上同属一块固态硬盘（例如 256GB NVMe SSD 的不同分区），两者的 4K 随机读写性能、IOPS 与通道带宽完全一致。将 Pagefile 迁移到 H 盘能够彻底切断 C 盘被虚拟内存暴撑的隐患，实现物理级零性能损耗。

### Q2: 为什么点击了虚拟内存迁移，C 盘的 19GB 没有立即变少？
**答：因为旧的 `C:\pagefile.sys` 处于当前 Windows 内核的排他性读写锁中。**  
设置完成后需要**重启一次电脑**。重启时 Windows 会在新设定的盘符（如 H 盘）创建新的页面文件并解绑 C 盘，旧文件随后会自动清除或可一键删除。

### Q3: 为什么软件不直接帮我删除微信/QQ 的聊天文件夹？
**答：这是最高级别的数据安全防范机制。**  
聊天数据库（如 `nt_msg.db`、`message.db`）涉及用户私密工作数据与未保存文件。工业级工具坚决杜绝自动化粗暴强删，仅对其进行统计并引导用户在客户端内合规操作。
